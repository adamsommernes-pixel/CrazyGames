# Åland – Mellan två riken

A roughly 5-minute Swedish-language documentary about the history of the Åland Islands. Everything in it is generated by code in this folder: the narration, music, sound design, maps, animations and typography.

## What's in the film

- **Narration**: the script is in `narration.py`. The voice is Piper TTS with the Swedish NST voice. Each line is synthesized one sentence at a time, and several takes are made per sentence. Years and place names are spelled out phonetically so they're pronounced correctly. The voice then gets a dark, close "PSA" treatment: EQ, compression, light saturation and a bit of room (`tts.py`, `audio_vo.py`).
- **Imagery**:
  - Real Sentinel‑2 satellite images of Åland (Copernicus, 14 June 2020), stitched into a 10 m mosaic.
  - Maps built from Natural Earth data.
  - A globe using the three.js earth texture.
  - Procedurally rendered sea, storm and sunset scenes.
  - Hand-drawn-style line drawings: Jomala church, Kastelholm castle, the Bomarsund plan, Pommern and the Victoria Cross.
  - Rock carvings painted on red granite, a waving Åland flag, documents and a stamp.
- **Music**: an original orchestral score, composed as MIDI in code (`audio_music.py`) and rendered with the MuseScore General soundfont through fluidsynth.
- **Sound**: wind, sea, cannons, pen scratches, a clock and a flapping flag are all synthesized. `audio_mix.py` then applies reverb, ducks the music under the voice, and levels the final mix to −16 LUFS.

## Building

```bash
sudo apt-get install ffmpeg fluidsynth musescore-general-soundfont-lossless
pip install numpy scipy opencv-python-headless pillow pyproj shapely piper-tts librosa soundfile pyloudnorm pedalboard mido mgrs
./fetch_assets.sh                 # voice, satellite data, map data, fonts
python3 prep_s2.py                # mosaic + NIR
python3 -m film.sat               # image pyramid + land mask
python3 tts.py && python3 audio_vo.py      # voice + timeline
python3 audio_music.py && python3 audio_mix.py
python3 render.py video --jobs 4           # picture (build/video_only.mp4)
ffmpeg -i build/video_only.mp4 -i build/mix.wav -c:v copy -c:a aac -b:a 256k -shortest Aland.mp4
```

To check individual frames: `python3 render.py stills 12.5 130` or `python3 render.py sheet`.

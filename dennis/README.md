# Dennis – ett porträtt

A roughly 7-minute Swedish-language portrait film about Dennis Eriksson from Åland. The narration, subtitles, animation, maps, music and mix are all generated by code in this folder. The film also uses five photos and two phone videos that aren't in the repo (see *Media* below).

It builds on the Åland film in `../aland`. That project provides the shared rendering helpers, the map and Sentinel‑2 satellite data, the fonts and the Swedish Piper voice.

## Contents

- **Narration**: the script is in `narration.py`, with pronunciation fixes for names and loanwords. It is voiced with Piper's Swedish NST voice (`tts.py`) and given a warm, close treatment in `vo.py`. The voice is already deep, so the pitch is left unchanged.
- **Picture** (`film_d/`):
  - A globe that dives into Åland, then a satellite shot where the islands' inhabitants light up and all fade except one.
  - A map of Norway for the psychiatry years.
  - A people infographic for his work helping people into jobs.
  - Mariehamn from satellite.
  - An animated family tree that ends with Napso's paw prints.
  - Topographic terrain with a running pack and a Canis Løphus badge.
  - Hand-drawn fiddle, guitar and ukulele.
  - A satellite geolocation that zooms into the real fiddle clip.
  - A phone UI gag for the tech chapter, and a "HEMLIGT" document before the shh clip.
  - Line drawings of the Julius café.
  - A 2.5D parallax move on every photo.
- **Music** (`music.py`): an original waltz theme for violin, guitar, piano and strings, rendered with fluidsynth. The score goes quiet while Dennis's own fiddle clip plays.
- **Mix** (`mix.py`): narration, score, the clips' original audio and a few light sound effects, normalized to −16 LUFS.

## Media (not committed)

`media/` holds the family's own photos and videos (`cafe.jpg`, `vacuum.jpg`, `portrait.jpg`, `steps.jpg`, `pointer.jpg`, `fiddle.mov`, `shh.mov`). They are kept out of git on purpose.

## Building

```bash
# requires ../aland/assets (./fetch_assets.sh), the satellite pyramid (prep_s2.py + film.sat) and pip install rembg
python3 prep_media.py              # masks/plates for parallax, 25 fps frames + audio from the clips
python3 tts.py && python3 vo.py    # voice + timeline (build/timeline.json)
python3 music.py && python3 mix.py # score + final mix (build/mix.wav)
python3 render.py sheet            # contact sheet for checking
python3 render.py video --jobs 4 --preset medium --crf 16 > build/render.log 2>&1
./finalize.sh                      # Dennis_1080p.mp4 + Dennis_720p.mp4
```

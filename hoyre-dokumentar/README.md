# «Tre vinduer» – produksjonspakke

En animert minidokumentar på ca. 7 minutter fra **Høyre** om rus, integrering og trygghet. Stilen er «armchair»-dokumentar: lav-poly 3D-dioramaer, dempet palett og Høyre-blå som eneste aksentfarge.

| Fil | Innhold |
|---|---|
| `01-manus.md` | Fortellermanus med tidskoder, regi og kildehenvisninger (≈ 967 ord) |
| `02-shotliste.md` | 34 shots med tid, varighet, visuelt, kamera, tekst på skjerm og lyd |
| `03-bildeprompter.md` | Bilde- og bevegelsesprompter per shot, med fast stil- og negativblokk |
| `04-musikk-og-lyd.md` | Musikk og lyddesign per kapittel |
| `05-kildeliste.md` | Kilde og år for hvert tall (K1–K27), med verifiseringsstatus |
| `06-titler-og-thumbnails.md` | Tre titler og tre thumbnail-konsepter |
| `../hoyre-film/` | Filmen laget i kode fra denne pakken (utkast), med produksjonstid i `PRODUCTION-TIME.md` |

Kapittel 3 (det valgfrie temaet) handler om **trygghet**: kriminelle nettverk som rekrutterer unge. Temaet er valgt fordi det binder sammen de to andre kapitlene.

## Før innspilling: dette må gjøres

1. **Faktasjekk alle tall** mot lenkene i `05-kildeliste.md`. Ingen tall er lest direkte på primærkilden (se forklaringen øverst i kildelisten). Prioriter radene merket SJEKK.
2. **Fyll inn plassholderne:**
   - `[STAT NEEDED]` i kapittel 1 (K8), tilbakefall etter rusbehandling.
   - `[INSERT URL]` (sluttkortet) og `[INSERT URL TIL KILDELISTE]`.
   - `[HEX]`, Høyres eksakte blåfarge.
   - `[QUOTE FROM HØYRE SPOKESPERSON – TO BE APPROVED]` (valgfritt, i syntesen).
3. **Godkjenning av politikk:** Høyres standpunkter (K13, K22, K26) er hentet fra programmet for 2025–2029, hoyre.no og valgmateriell. Fagansvarlig i Høyre må godkjenne ordlyden.
4. **Motstandernes standpunkter** (K12, K21) skal kontrolleres mot partienes egne program. Det er én nøytral setning per parti, og partiene skal ha lik visuell behandling.
5. **Redaksjonelt valg:** Manuset sier åpent at Høyre var med på rusforliket i 2025. Det er gjort for å være åpen, og bør beholdes.

## Merking og regelverk

- Sluttkortet sier «Produsert av Høyre», og tittelkortet sier «En dokumentar fra Høyre».
- Politisk reklame på TV er forbudt i Norge (kringkastingsloven). Filmen er laget for nett og sosiale medier.
- Ved betalt spredning gjelder plattformenes regler for politiske annonser («Betalt av Høyre»). Merk også at bildene er KI-generert eller animert dersom plattformen krever det.
- Ingen eksisterende kanalers navn, logo, intro eller musikk brukes. Musikken er original (se `04-musikk-og-lyd.md`).

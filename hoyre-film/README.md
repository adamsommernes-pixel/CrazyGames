# «Tre vinduer» – the film

The rendered version of the production package in `../hoyre-dokumentar`. It is a 6:49 animated mini-documentary in Norwegian (bokmål), made in a low-poly miniature-diorama style. Everything is generated by code in this folder:

- narration (Piper TTS, Norwegian voice)
- 3D dioramas and camera moves
- on-screen numbers and source lines
- score and sound design

**Status: DRAFT.** Every frame carries a small `UTKAST · ikke faktasjekket · ikke godkjent` tag until `config.DRAFT` is set to `False`. Per `../hoyre-dokumentar/README.md`, none of the numbers have been checked against primary sources, and Høyre has not approved the wording.

## Before it can be published

Everything Høyre has to supply sits in **`config.py`**. Change it, re-run, done.

| Placeholder | Where | What happens now |
|---|---|---|
| `[HEX]` – Høyre's exact blue | `config.HOYRE_BLUE` | A stand-in blue (`#1f5fbf`) |
| Høyre's logo | `config.LOGO_PNG` | A grey `[HØYRES LOGO]` box on the end card |
| `[INSERT URL]`, `[INSERT URL TIL KILDELISTE]` | `config.URL`, `config.SOURCES_URL` | Shown as visible placeholders on the end card |
| `[STAT NEEDED]` (K8, chapter 1) | `manus.py`, line `a4` | The sentence is left out; add it and every shot re-times itself |
| Fact check (K1–K27) | on-screen text lives in `film/shots.py` (search for the number) | Numbers as in `05-kildeliste.md` |
| Draft tag | `config.DRAFT = False` | Shown on every frame |

The optional spokesperson quote is not used.

Other deviations from `02-shotliste.md`:
- The optional 1-second opioid insert in S10 and the optional word-card text in S03 are skipped.
- The master is 1080p. Set `config.SCALE` for 4K, at about 4× the render time.
- There is no 9:16 cut yet.
- Subtitles ship as a sidecar file (`Tre_vinduer.no.srt`) instead of being burned in, because the stat and source lines already use the bottom of the frame.

## How it is built

| File | What it does |
|---|---|
| `manus.py` | The script, word for word from `01-manus.md`, plus how numbers are read aloud |
| `tts.py`, `audio_vo.py` | Voice, three takes per sentence (median kept); processing; **`build/timeline.json`**, which every shot, caption, music cue and sound effect is timed from |
| `film/raster.py` | A small software renderer (numba): z-buffer, sun shadows, window/lamp/spot lights, wet-asphalt highlights, decals, tilt-shift depth of field, bloom |
| `film/kit.py` | Reusable pieces: houses, windows, faceless figures, furniture, bars, plinths, lamps, trees |
| `film/world.py` | **One town set**: the street with the three windows, harbour, station, school, clinic, municipal offices, police house, courthouse, pitch |
| `film/rooms.py` | The three windows as cut-away rooms (night and day) |
| `film/sets.py` | Title letters, the Norway map, the evidence board, party plinths, and the small sets for chapters 2–3 |
| `film/overlay.py` | One template per graphic: stat card, source line, bullet list, chapter card, label, chat bubble |
| `film/shots.py` | The 34 shots, each anchored to its line in the narration |
| `audio_music.py` | Original score in code (D minor → D major, three-note motif), rendered with fluidsynth |
| `audio_mix.py` | Synthesized foley/ambience, ducking, −16 LUFS master |

```bash
sudo apt-get install ffmpeg fluidsynth musescore-general-soundfont-lossless
pip install numpy scipy numba opencv-python-headless pillow shapely piper-tts librosa soundfile pyloudnorm pedalboard mido
./fetch_assets.sh
LS=1.08 python3 tts.py && python3 audio_vo.py         # voice + timeline (~1 min)
python3 audio_music.py && python3 audio_mix.py         # score + mix (~2 min)
python3 render.py sheet --ss 1                         # one frame per shot, for review (~1 min)
python3 render.py video --jobs 4 > build/render.log    # picture (~95 min on 4 cores)
./finalize.sh                                          # master + 720p (<30 MB) + subtitles
```

To check single frames: `python3 render.py stills 63 140`. To re-render part of the film, delete the blocks for that time range in `build/parts/` and run `render.py video` again. Finished blocks are skipped.
